# Hermes Voice — голосовой контур

Живой разговор голосом с агентом Hermes: колонка слышит ключевое слово, распознаёт фразу,
отправляет её агенту, ответ синтезируется и звучит в колонке. Распознавание и синтез —
локальные модели, наружу не уходит ничего.

В репозитории весь контур: панель в браузере, серверный хаб, агент на колонке и документация.

## Компоненты

| Компонент | Что делает | Где живёт | Порт |
|---|---|---|---|
| **voice-hub** | единая точка входа: WebSocket на каждого клиента, внутри — речевой автомат и диалог с агентом | хост с хабом | 8796 |
| **voice-panel** | веб-панель: микрофон из браузера, окна, трансляция рабочего стола | тот же хост | 8792 |
| **voice-agent** | программа на колонке: микрофон, кольцевой буфер, звук ответа, кольцо и музыка | Яндекс Станция | — |
| **речевой шлюз** | распознавание и синтез за одним HTTP-шлюзом | отдельная машина с моделями | 8000 |

Модели вынесены на отдельную машину намеренно: они тяжёлые, а хаб и панель — лёгкие.
И распознавание, и синтез идут **через один шлюз** (`/v1/audio/transcriptions` и
`/v1/audio/speech`): второй путь к тем же моделям не держим.

Все адреса задаются переменными окружения — в коде и документации стоят плейсхолдеры
`<hub-host>`, `<speech-host>`, `<station-host>`.

## Как идёт звук

```
колонка ──PCM 16 кГц──▶ voice-hub:8796
                          ├─ детектор ключевого слова
                          ├─ проверка ключа через распознавание
                          ├─ сбор фразы (речь/тишина + Smart Turn)
                          ├─ ASR → текст            (речевой шлюз)
                          ├─ агент Hermes           (:9119)
                          └─ TTS → mp3              (речевой шлюз)
                          │
колонка ◀──mp3-кадры──────┘   + команды: кольцо, звук, пауза/продолжить
```

Панель подключается к тому же хабу тем же протоколом, только микрофон берёт из браузера.

## Структура репозитория

Каждый сервис — отдельная папка со своим кодом, юнитами и инструкцией.

```
hub/                  сервер хаба (Python)
  voice_core.py         автомат: активация, проверка ключа, сбор фразы, окно диалога
  voice_loop.py         детектор слова, AGC, сборщик фразы, клиент распознавания
  voice_hub.py          WebSocket-хаб: один канал на клиента, команды устройству
  voice_dialog.py       слой диалога с агентом, не знает о транспорте
  hermes_ws.py          клиент агента: подача текста, поток ответа, события инструментов
  wake_gate.py          локальный детектор ключевого слова (TFLite)
  ha_morph.py           стеммер и матчер устройств Home Assistant (падежи не важны)
  ha_route.py           быстрый дом: команды и показания HA без модели
  fast_route.py         развилка «быстрый дом или агент» для DialogTurn
  smart_turn.py         семантический конец реплики (ONNX)
  voice_fillers.py      фразы-заполнители тишины (выключены по умолчанию)
  voice_capture.py      сбор окон событий в датасет ключевого слова
  kws_train_cleanup.py  обслуживание датасета обучения
  models/               модель ключевого слова
  fillers/              готовые фразы-заполнители тишины
  tests/                тесты поведения
  deploy/               systemd-юнит хаба

agent/                агент колонки (Go)
  main.go, ws.go, wsloop.go, control.go
  deploy/S99zhermes     init-скрипт для колонки

panel/                веб-панель
  server.py             HTTP/WS-сервер панели, раздаёт собранный фронтенд
  frontend/             исходники фронтенда (Vite + React)
  deploy/               systemd-юниты панели и живого браузера, скрипт запуска Chrome

scripts/              утилиты, не входящие в сервисы
  export_dataset.py     сборка обучающего набора
  recolor_led.py        перекраска кольца колонки
  station-tts.sh        провайдер синтеза для колонки
  make-fillers.py       генерация фраз-заполнителей

docs/                 документация
.gitea/workflows/     CI
```

## Быстрый старт

Нужны Python 3.10+, Node 18+ (для сборки панели) и Go 1.21+ (только для агента).

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

cd panel/frontend
npm ci
npm run build          # соберёт panel/dist — его отдаёт server.py
```

Настройки — в `.env` рядом с репозиторием (шаблон: `.env.example`). Панель читает его через
`EnvironmentFile` юнита, хаб — через переменные окружения процесса. Реальный `.env` в git не
попадает.

Запуск без systemd, для отладки:

```bash
.venv/bin/python hub/voice_hub.py --port 8796 --out /tmp/station-hub
python3 panel/server.py
```

## Конфигурация

| Переменная | Где | Смысл |
|---|---|---|
| `VOICE_PORT` | панель | порт панели (8792) |
| `VOICE_HUB_URL` | панель | WebSocket хаба |
| `VOICE_CDP_URL`, `VOICE_VNC_HTTP`, `VOICE_VNC_WS` | панель | живой браузер и трансляция стола |
| `ASR_URL` | хаб | эндпоинт распознавания (`/v1/audio/transcriptions`) |
| `TTS_URL` | хаб | эндпоинт синтеза (`/v1/audio/speech`) |
| `HERMES_WS_URL` | хаб | WebSocket агента Hermes |
| `HERMES_DASH_TOKEN_FILE` | хаб | файл с токеном агента |
| `HASS_URL`, `HASS_TOKEN` | хаб | Home Assistant для быстрого дома; без них модуль выключен |
| `STATION_ENTITY` | хаб | колонка, чья комната считается «комнатой по умолчанию» |
| `VOICE_FILLER_DIR` | хаб | каталог фраз-заполнителей |
| `VOICE_SILENCE_MS`, `VOICE_HARD_SILENCE_MS`, `SMART_TURN_THRESHOLD` | хаб | пороги конца реплики |

Полный список с пояснениями — в `.env.example` и `docs/deploy.md`.

## Управление сервисами

```bash
systemctl status voice-panel voice-hub
systemctl restart voice-hub
journalctl -u voice-hub -f                 # активация, фраза, ответ, тайминги
curl -s http://127.0.0.1:8796/health       # кто подключён и в каком состоянии
```

Колонка:

```bash
ssh -p 2222 root@<station-host>
/etc/init.d/S99zhermes restart
tail -f /tmp/hermes-agent.log
```

## Что выведено из работы

- **TCP-сервер колонки** (`voice_station.py`, порты 8797–8799) — заменён хабом на WebSocket,
  код удалён.
- **Wyoming-мосты** (`wyoming_*.py`) — удалены: панель ходит через хаб, дом — через REST и
  реестры Home Assistant, распознавание и синтез свои по HTTP. Wyoming вернётся только если
  отдавать наши модели внутрь HA Assist; тогда файлы берутся из предыдущих версий репозитория.
